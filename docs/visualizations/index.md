# HighDimProb Visualizations

This directory contains a lightweight visualization layer for humans and agents
working on HighDimProb. The diagrams are documentation artifacts only: they do
not promote modules, prove theorems, or change theorem meanings.

## Files

| File | Format | Source | Purpose |
|---|---|---|---|
| `module_tree.mmd` | Mermaid | curated from `docs/ModuleTree.md` and `docs/BranchRegistry.md` | Root-to-branch-to-leaf structure and stability status. |
| `import_graph.dot` | Graphviz DOT | generated by `scripts/visualize_imports.py` | Exact Lean import graph, clustered by logical branch, with every importer-to-imported edge preserved. |
| `import_graph_summary.dot` | Graphviz DOT | generated by `scripts/visualize_imports.py` | Mathlib-style core branch summary: API aggregate fan-out and examples are omitted, and each node is labelled with its module count. |
| `import_branches/*.dot` | Graphviz DOT | generated by `scripts/visualize_imports.py` | Focused branch import graphs. Large branches are grouped into conceptual layers, and external branch imports are shown as dashed boundary nodes. |
| `scalar_concentration_spine.mmd` | Mermaid | curated from scalar milestone docs | Main scalar concentration implication spine. |
| `hoeffding_path.mmd` | Mermaid | curated from `docs/HoeffdingMilestone.md` | Rademacher and bounded-variable Hoeffding theorem paths. |
| `bernstein_path.mmd` | Mermaid | curated from `docs/BernsteinPlan.md` | Scalar Bernstein and weighted Bernstein proof path. |
| `random_matrix_branch.mmd` | Mermaid | curated from `docs/MatrixConcentrationPlan.md` | Random matrix infrastructure and statement status. |
| `kg_to_lean_mvp.mmd` | Mermaid | curated from `external/validation/mvp-kg-to-lean*/` | KG-to-Lean validation workflow path. |

## Viewing Mermaid

Mermaid files can be viewed directly in GitHub, VS Code extensions, or any
Mermaid renderer. They are written as standalone `flowchart TD` diagrams.

## Rendering DOT

If Graphviz is installed, render the import graph with:

```bash
dot -Tsvg docs/visualizations/import_graph.dot -o docs/visualizations/import_graph.svg
```

Render the branch summary and a focused branch graph with:

```bash
dot -Tsvg docs/visualizations/import_graph_summary.dot -o docs/visualizations/import_graph_summary.svg
dot -Tsvg docs/visualizations/import_branches/randommatrix.dot -o docs/visualizations/import_branches/randommatrix.svg
```

Graphviz is optional and is not a project dependency.

## Updating The Import Graph

Regenerate `import_graph.dot` after Lean import changes with:

```bash
python scripts/visualize_imports.py
```

The script uses only the Python standard library. It scans `HighDimProb.lean`
and `HighDimProb/**/*.lean`, extracts lines beginning with
`import HighDimProb`, and writes:

- an exact full graph for import auditing;
- a higher-level core branch summary, omitting API aggregate fan-out and
  examples so the dependency shape is readable;
- focused branch graphs that keep file nodes but group large branches into
  conceptual layers.

## Status Policy

- `stable` means reachable through `import HighDimProb`.
- `experimental` means reachable through `import HighDimProb.Experimental`.
- `typed Prop` means proof-ready or proof-planning statement vocabulary, not a
  proved theorem.
- `TODO` nodes are documentation-only unless a Lean declaration is named
  explicitly in the owning source file and theorem atlas.
