# Contributor Roadmap

HighDimProb is currently at Milestone 1 / v0.1-alpha. The stable probability object layer is usable; high-dimensional modules are experimental.

## Good First Issues

- Add examples for existing stable declarations.
- Improve `docs/TermMap.md` entries.
- Add typed theorem statements for covering/packing results.
- Add tests for experimental scaffold modules.

## Object-Layer Tasks

- Stage 5B covering/packing theorem statement layer.
- Stage 6A random matrix object layer.
- Gaussian width vocabulary.
- Random process vocabulary.
- Empirical process vocabulary.

## Theorem-Layer Tasks

These are not good first issues:
- subGaussian equivalence
- subExponential equivalence
- Hoeffding
- Bernstein
- Hanson-Wright
- Johnson-Lindenstrauss
- covariance estimation
- generic chaining
- signal recovery
